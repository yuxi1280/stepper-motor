一、面板按键操控（小屏幕）
================================================================================
  操作                            功能
  ------------------------------  --------------------------------------------
  按 Next                        角度界面下切换显示：角度/电流/相电阻电感等
  按 Enter                       进入参数设置菜单；菜单内确认/进入选项
  菜单中长按 Next 1秒            返回角度显示界面
  按住 Next+Enter 上电 5秒       快速恢复出厂设置
  长按 Enter 3秒                 (Lock=Enable 锁定菜单时)进入参数设置菜单
  按 2 下 Enter                  解除堵转保护(Clog_Pro=Enable 时)
  Restore→Yes                    恢复出厂，蓝灯常亮后需断电重上电+空载校准

二、通讯帧格式
================================================================================
【自由协议（默认，串口 TTL/RS485/CAN）】
  帧格式：  地址(1B) + 功能码(1B) + 命令数据(nB) + 校验码(1B)
  - 地址范围 1~255，出厂默认 1；0x00 = 广播地址
  - 校验码默认固定 0x6B；可改为 XOR / CRC-8 / Modbus-RTU / DMX512
    (菜单 Checksum 中设置)
  - CAN 通讯：固定扩展帧，帧ID = (Addr << 8) | Packet
    * 每包数据 <= 8 字节；>8 字节需拆包发送，Packet 从 0 开始计数
    * 每包第一个字节为功能码

【电机返回码】
  返回码   含义
  ------   ------------------------------------------------
  02       命令正确
  12       触发回零时当前已在零点/回零限位已触发，电机不动
  E2       参数错误(数据范围不满足；含低压/堵转/过流过热保护触发)
  EE       命令格式错误
  9F       动作执行完成(电机主动返回)：
            到位返回      = 地址 + FB/FD + 9F + 校验码
            回零完成返回  = 地址 + 9A  + 9F + 校验码
            夹爪夹紧返回  = 地址 + F5  + 9F + 校验码

2. 运动控制命令
----------------------------------------
  通用说明：
    同步标志 00 = 立即执行 / 01 = 先缓存当前命令(等待触发多机同步)
    运动模式 00 = 相对上一次输入位置 / 01 = 相对坐标零点(绝对) / 02 = 相对当前实时位置

  命令                            功能码  数据构成
  -------------------------------  ------  ------------------------------------
  多电机命令                       AA      总字节数 + 各电机完整命令
                                          (仅地址1电机回复；Modbus 不支持)
  电机使能控制                     F3      AB + 使能(00/01) + 同步标志
  力矩模式控制 (X)                 F5      符号 + 斜率(mA/S) + 电流(mA) + 同步
  力矩模式限速控制 (X)             C5      符号 + 斜率 + 电流 + 同步 + 最大速度(0.1RPM)
  速度模式控制 (X)                 F6      方向 + 加速度(RPM/S) + 速度(0.1RPM) + 同步
  速度模式限电流控制 (X)           C6      方向 + 加速度 + 速度 + 同步 + 最大电流(mA)
  速度模式控制 (Emm)               F6      方向 + 速度(RPM) + 加速度(00-FF) + 同步
  直通限速位置模式控制 (X)         FB      方向 + 速度(0.1RPM) + 位置(0.1°) + 运动模式 + 同步
  直通限速位置模式限电流控制 (X)   CB      方向 + 速度 + 位置 + 运动模式 + 同步 + 最大电流
  梯形曲线加减速位置模式控制 (X)   FD      方向 + 加速加速度 + 减速加速度 + 最大速度 + 位置 + 运动模式 + 同步
  梯形曲线位置限电流控制 (X)       CD      上 + 最大电流
  位置模式控制 (Emm)               FD      方向 + 速度(RPM) + 加速度 + 脉冲数(int32) + 运动模式 + 同步
  快速位置模式控制 (Emm,≥V2.0.0)  F1→FC   F1: 速度+加速度+运动模式+同步  /  FC: 脉冲数(int32)
  快速梯形曲线位置控制 (X,≥V2.0.0) F1→FC   F1: 加/减速+最大速度+运动模式+同步+最大电流 / FC: 位置(0.1°)
  立即停止                         FE      98 + 同步标志
  触发多机同步运动                 FF      66 (广播地址发送，缓存过命令的电机同步启动)

  参数范围：
    斜率/加速度(RPM/S, mA/S)   0000-FFFF (0~65535)
    速度(X, 0.1RPM)            0000-7E30 (0~3000.0RPM)
    速度(Emm, RPM)             0000-0BB8 (0~3000RPM)
    电流(mA)                   0000-1388 (0~5000mA)
    位置角度(0.1°)             有符号 int32

3. 原点回零命令
----------------------------------------
  命令                        功能码   辅助码/数据
  ---------------------------  ------  ----------------------------------------
  设置单圈回零的零点位置        93      88 + 是否存储(00/01)
  触发回零                     9A      回零模式(00-05) + 同步标志
  强制中断并退出回零操作        9C      48
  读取回零状态标志              3B      -
  读取回零参数                  22      -
  修改回零参数                  4C      AE + 存储 + 模式+方向+速度+超时+碰撞检测+O_POT_En

  触发回零模式(9A):
    00 = 单圈就近回零 / 01 = 单圈方向回零 / 02 = 无限位碰撞回零
    03 = 限位开关回零 / 04 = 回到绝对位置坐标零点 / 05 = 回到上次掉电位置角度

  回零状态标志(3B) 位定义:
    bit5=Ocp_TF 过流保护 / bit4=Otp_TF 过热保护
    bit3=Org_CF 回零失败 / bit2=Org_SF 正在回零
    bit1=Cal_Rdy 已校准 / bit0=Enc_Rdy 编码器正常
    程序判断: 回零状态标志&0x0C => 0x04 正在回零 / 0x08 回零失败 / 0x00 回零成功

四、MODBUS-RTU 要点
================================================================================
  1. 启用：电机菜单 Checksum 设为 Modbus（默认自由协议）
     默认通讯参数：115200 / 8 / N / 1
  2. 功能码：
     读寄存器   03H / 04H（X42 仅支持 04H；X42S/Y42 两者皆可）
     写单寄存器 06H（触发动作类命令）
     写多寄存器 10H（运动控制类、参数类命令）
  3. 寄存器起始地址 = 自由协议功能码
     - 触发动作：06=编码器校准 / 08=重启 / 0A=位置清零 / 0E=解除保护 / 0F=恢复出厂
       数据写 0001
     - 运动/参数命令的寄存器地址因固件而异：
       文档中标红色 = Emm 固件地址，标蓝色 = X 固件地址，标绿色 = 两固件相同
       例：电机使能 F3(E0)；力矩模式 E2；速度模式 E6
  4. 错误返回格式：发送命令的功能码 | 0x80
  5. X 固件 32bit 数据先传低字、再传高字（高低字自动对调）
  6. Modbus-RTU 暂不支持多电机命令(AA)
  7. 可用配套上位机或通用 Modbus 调试助手(自动算 CRC16)调试

附注
================================================================================
  1. X 固件与 Emm 固件命令差异：
     - 力矩模式仅 X 固件有；Emm 固件无力矩模式
     - 速度/位置模式命令格式不同；位置角度/误差格式不同
     - 读取/修改系统状态参数、驱动配置参数格式不同
  2. 位置模式命令可打断：新位置命令发送后实时更新、平滑过渡
  3. 堵转保护触发条件：实际转速<阈值 + 相电流>阈值 + 持续时间>阈值
  4. 快速位置模式(F1/FC) 需固件 V2.0.0 以上
  5. 恢复出厂设置后需断电重上电，并重新空载校准(Cal_MFL)
